# Інтерактивний навчальний модуль з інформатики (10 клас)

**Теми уроків:**
1. **Професії та ролі фахівців у сфері ІТ** (SDLC, Tech та Non-Tech ролі, порівняння PM та Product Manager, Hard/Soft skills, система грейдів).
2. **Розвиток штучного інтелекту та вплив на майбутні професії** (ієрархія AI → ML → DL → Generative AI, ANI/AGI/ASI, автоматизація та аугментація, нові ШІ-професії, галюцинації, bias, human-centric skills).

## Функціонал вебдодатка
- **📖 Теоретичний довідник** — кнопка швидкого доступу до структурованого конспекту обох уроків із перемиканням між темами.
- **🎮 Інтерактивний симулятор** — 8 практичних кейсів («ІТ-рекрутер та ШІ-стратег») із миттєвим зворотним зв'язком та поясненнями.
- **📝 Тестування (12 запитань)** — підсумкова перевірка знань (по 6 запитань до кожного уроку) з автоматичним підрахунком балів за 12-бальною шкалою та підсвічуванням правильних відповідей.

## Як розгорнути на GitHub Pages
1. Створіть новий публічний репозиторій на [GitHub](https://github.com).
2. Завантажте в корінь репозиторію всі файли з цього архіву (`index.html`, `README.md`, `.nojekyll`).
3. Перейдіть у **Settings → Pages**.
4. У розділі **Build and deployment → Source** виберіть **Deploy from a branch**, оберіть гілку `main` та папку `/ (root)` і натисніть **Save**.
5. Через 1–2 хвилини ваш інтерактивний урок буде доступний за прямим посиланням для учнів.
